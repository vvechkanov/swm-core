# swm-core

Модуль Foundry VTT для мира **Space West Marches** (система SWADE):

- **тема «Лоция»** — интерфейс и журналы в стиле вики «Ближний пояс» (шрифты Unbounded и Onest внутри модуля);
- **живая карта сектора** — звёзды, маршруты и кольцо дальности рисуются модулем по данным мира (журналы систем и флаги сцены).

В мирах других систем модуль ничего не делает (и Foundry предлагает его только для SWADE).

Foundry **14** (проверено на 14.368), SWADE 6.

## Установка

Foundry → **Add-on Modules** → **Install Module** → в поле **Manifest URL** вставить:

```
https://github.com/vvechkanov/swm-core/releases/latest/download/module.json
```

Потом включить модуль в мире: **Game Settings → Manage Modules → Space West Marches — ядро**.

Обновления приходят сами: в списке модулей появится кнопка **Update** (или «Check for Updates»).

## Как выпустить версию

1. Поменять код, закоммитить в `main`.
2. Поставить тег с новой версией и запушить:
   ```
   git tag v0.2.0
   git push origin main --tags
   ```
3. GitHub Actions (`.github/workflows/release.yml`) сам:
   - подставит в `module.json` версию из тега, `manifest` и `download`;
   - соберёт `module.zip`;
   - выложит релиз с `module.json` и `module.zip`.

Версию в `module.json` в репозитории руками менять не нужно: там стоит `0.0.0`, настоящая берётся из тега.

## Настройки (у каждого игрока свои)

- **Тема «Лоция»** — включить или выключить оформление.
- **Анимация карты сектора** — огоньки на маршрутах, пульсация, голограмма. Выключить на слабом компьютере.
- **Живая туманность на карте сектора** — фон из `map.html`: движущаяся туманность и мерцающие звёзды (шейдер WebGL). Выключено — фоновая картинка сцены.

## Карта сектора

Работает на сцене с флагом `world.sector = true` («Ближний пояс — карта сектора»). Модуль сам рисует у каждого клиента:

- звёзды по журналам с флагами `world.sys`, `x`, `y`, `cls`, `g`, `st` (координаты в св. годах; на сцене `px = (x + 14) * 100`, `py = (12 − y) * 100` — ось y вверх, как в `map.html`);
- изученные маршруты из флага сцены `world.routes = [["home","olh"], …]`;
- кольца 5 и 10 св. лет вокруг станции (`sys = "home"`), легенду, шкалу;
- всё — как голограмма над столом: сканлинии, полоса развёртки, лёгкое мерцание (выключается вместе с анимацией).

**Видимость:** игрок видит систему, только если у него есть право хотя бы «Ограниченно» (LIMITED) на её журнал. Маршрут виден, только если видны оба его конца. Мастер видит всё; скрытые от игроков системы у него бледнее и подписаны «скрыта от игроков».

**Журнал системы** начинается с карточки, как в map.html: класс и статус, метки, сетка характеристик и «Одним прыжком отсюда» (только системы, которые видит читающий).

**Наведение** на звезду — пунктир и табличка от выбранного токена (корабля), а без него — от станции. **Клик** — открыть журнал системы.

**Мастеру:** правый клик по звезде — маршруты отсюда, «Открыть игрокам» / «Скрыть», журнал. Кнопка «Маршруты ближнего пояса» в панели токенов (только на этой сцене).

Подпись звезды ставится сама (туда, где нет маршрутов). Вручную — флаги журнала `world.lx`, `world.ly` (сдвиг в пикселях экрана) и `world.al` (`left`/`right` — выравнивание).

## API для макросов

```js
const api = game.modules.get("swm-core").api;
await api.addRoute("home", "kol");     // добавить разведанный маршрут
await api.removeRoute("home", "kol");  // убрать
await api.reveal("kol");               // открыть систему игрокам («Наблюдатель» на журнал)
await api.reveal("kol", "LIMITED");    // или другой уровень
await api.hide("kol");                 // скрыть
api.redraw();                          // перерисовать у себя
api.openRoutes();                      // окно маршрутов
await api.migrate();                   // проверка: что уберёт миграция
await api.migrate({ dryRun: false });  // убрать временную карту из тайлов и рисунков
api.previewAs("Тест-игрок");           // мастеру: карта глазами игрока (только у себя)
api.previewAs();                       // вернуть свой вид
```

Изменять (маршруты, видимость, миграция) может только мастер.
